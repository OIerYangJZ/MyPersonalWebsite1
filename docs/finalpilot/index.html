FinalPilot · Education

Exam review, organized from your own materials.

FinalPilot turns lecture slides, notes, difficult questions, and past exams into source-linked study notes and review packs. AI explains and suggests; the student reviews and confirms before anything is saved.

Features

Everything for one course, in one workspace.

Source-aware notes

Extract text page by page from PDFs, and link every Markdown note back to the file and page it came from.

Knowledge points & hard questions

Organize topics into a structure, track difficult questions with status and answers, and search the whole course.

Review packs

Generate exam review packs grouped by knowledge point, and export them with your notes and questions as Markdown.

Get started

Try it with the built-in demo course.

# from a clone of github.com/OIerYangJZ/FinalPilot

$ python3 -m venv .venv && source .venv/bin/activate

$ pip install -r backend/requirements.txt

$ python backend/scripts/create_demo_course.py

$ cd backend && uvicorn app.main:app --host 127.0.0.1 --port 8000

# in another terminal

$ cd frontend && npm install && npm run dev
