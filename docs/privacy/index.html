Privacy

This website

jinseylab.tech sets no cookies and runs no analytics or tracking scripts. It is hosted on GitHub Pages, which may log standard request data such as IP addresses under GitHub's privacy statement.

Our products

MyCoder, PaperPilot, and FinalPilot run on your own machine. Jinsey Lab does not operate servers that receive your code, papers, notes, or course materials. When you enable AI features, content is sent directly from your machine to the model provider you configure, under that provider's terms. API keys are stored locally.

Contacting us

If you email us or open a GitHub issue, we use what you send only to respond. To ask about or delete correspondence, write to contact@jinseylab.tech.
