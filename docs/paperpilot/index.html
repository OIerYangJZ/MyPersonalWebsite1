PaperPilot · Research

Follow arXiv without drowning in it.

PaperPilot ranks each day's arXiv papers against your research profile, opens them in a side-by-side reader, and writes structured AI notes — all stored locally as Markdown you own.

Features

From radar to notes in one place.

Daily arXiv radar

Ranks new papers by your field, keywords, exclusions, and categories, and shows why each one was recommended.

Reader workspace

Read the PDF and edit your Markdown notes side by side. Import by arXiv ID, URL, PDF, or TeX source.

Notes that survive regeneration

AI summaries and your own “My Notes” live in one file, and regenerating a summary never overwrites what you wrote.

Get started

Five commands to your first radar.

# from a clone of github.com/OIerYangJZ/PaperPilot

$ uv sync

$ uv run paperpilot init

$ uv run paperpilot refresh

$ uv run paperpilot list

$ uv run paperpilot serve
