Install MyCoder Alpha

# npm (Node 22.18+)

$ npm install -g mycoder-cli@alpha

# or Homebrew

$ brew tap OIerYangJZ/mycoder

$ brew trust OIerYangJZ/mycoder

$ brew install mycoder

# check your setup

$ mycoder doctor

Flagship product

MyCoder: an agent that says what it can enforce.

Install from npm Product page

Policy before action

Every tool call becomes an access request that a policy engine approves or refuses before the tool does anything.

Zero runtime dependencies

One process on Node 22.18+. The supply chain is the package itself, and published bytes are the bytes the release gate tested.

Bring your own model

Adapters for Anthropic Messages, OpenAI Responses, and OpenAI-compatible APIs such as DeepSeek, OpenRouter, or a local llama.cpp.

Honest accounting

Token and cost totals come from the session's own event log. Refused actions are reported separately from completed ones.
