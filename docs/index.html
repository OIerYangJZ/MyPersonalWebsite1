Flagship product

MyCoder: an agent that says what it can enforce.

Most agents ask you to trust them. MyCoder tells you, per dimension, what is actually isolated — before you type anything.

Product page Source ↗

Policy before action

Every tool call becomes an access request that a policy engine approves or refuses before the tool does anything.

Zero runtime dependencies

One process on Node 22.18+. Published bytes are the bytes the release gate tested, with npm provenance.

Bring your own model

Adapters for Anthropic Messages, OpenAI Responses, and OpenAI-compatible APIs such as DeepSeek or a local llama.cpp.

Honest accounting

Token and cost totals come from the session's own event log. Refused actions are reported separately from completed ones.
